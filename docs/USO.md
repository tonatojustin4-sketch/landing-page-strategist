# Uso de Landing Page Strategist

## Flujo completo

Invoca la skill y explica lo que ya sabes. Ella debe preguntar por los vacíos que cambian la página y construir cuando tenga información suficiente. No necesitas completar un formulario exhaustivo antes de conversar.

```text
Usa $landing-page-strategist para crear una landing funcional para mi negocio.
Quiero que me entrevistes por bloques y luego construyas el proyecto completo,
lo pruebes y me entregues instrucciones para personalizarlo y publicarlo.
```

## Trabajo para un cliente

```text
Usa $landing-page-strategist. Estoy haciendo una web para un cliente que
vende servicios de limpieza de oficinas. Queremos solicitudes de presupuesto.
Ya tenemos logo, fotos y un WhatsApp. La página debe quedar editable y lista
para entregar con instrucciones. Pregunta lo que falte y desarrolla la landing.
```

Los negocios de los ejemplos son hipotéticos. No deben convertirse en clientes reales, testimonios ni casos de éxito dentro de una página publicada.

## Producto o formación

```text
Usa $landing-page-strategist para una landing de un curso de fotografía.
Tenemos un checkout externo. Necesito que la página explique el programa,
resuelva dudas y lleve al enlace de compra real. Entrevístame sobre el público,
contenidos, precio y evidencia disponible antes de escribir afirmaciones.
```

## Proyecto existente

```text
Usa $landing-page-strategist en este proyecto. Conserva su stack y revisa
lo que ya existe. Quiero mejorar la oferta, los textos y el recorrido de reserva,
y después implementar y probar los cambios en móvil y escritorio.
```

## Solo estrategia o prompt

```text
Usa $landing-page-strategist solo para preparar el brief, copy y un prompt
autosuficiente de implementación. En este encargo no construyas la web.
```

## Información útil para empezar

Nombre y oferta, público, mercado, objetivo, canal de tráfico, diferencias demostrables, alcance y precio, objeciones, evidencia autorizada, identidad de marca, fotos y destino del CTA. Si falta algo, la entrevista lo recaba progresivamente.

## Qué debes comprobar al recibir una web

Comprueba que puedes ejecutarla con la guía, editar los datos del negocio y seguir la acción principal. Confirma qué servicio recibe las solicitudes o procesa las compras, quién es titular de sus cuentas y qué costes recurrentes tiene. Revisa la visualización móvil y el inventario de recursos.

Una página estática con un enlace de WhatsApp real puede resolver una captación sencilla. Una reserva con disponibilidad o un checkout propio requiere servicios y conexiones adicionales. La skill debe ajustar la solución al encargo y explicar qué está integrado, probado o pendiente.

## Alcance de la primera versión

Esta publicación entrega el flujo y los recursos de la skill junto a un instalador verificable. No incluye una plantilla visual fija ni ejemplos de páginas construidas. La validación estructural y del instalador no demuestra calidad visual o rendimiento comercial: cada proyecto necesita su propia ejecución y revisión.
